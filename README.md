# Corazón de Maíz

Juego de granja en el señorío de Tlaxcallan, año 1519. Siembra la milpa, cría animales, comercia en el tianguis, honra a los dioses y une a los pueblos contra Tenochtitlan.

**Jugar:** abre `index.html` en el navegador, o entra a la página de GitHub Pages de este repositorio.

Controles básicos: flechas o WASD para caminar, Espacio para usar la herramienta, E para hablar o usar, Tab para la bolsa, M para el mapa y Esc para la pausa.

La intro animada con la canción está en `corazon-de-maiz-intro.html`: se ve al empezar una partida nueva o desde la portada ("Ver la intro"). Tiene que estar junto a `index.html`.

Las partidas se guardan en el navegador de cada jugador.
